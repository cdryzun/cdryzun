## What I build

I build AI-native developer platforms that connect private model serving, secure API gateways, MCP tools, Kubernetes delivery, and production observability.

I am a CKA/CKS-certified engineer with seven years of experience turning infrastructure, delivery, and AI tooling into reliable internal platforms.

- **AI infrastructure** — self-hosted model access, provider-compatible gateways, quota and audit controls, and MCP integrations.
- **Platform engineering** — Kubernetes, GitLab CI/CD, GitOps, reusable delivery templates, and developer self-service.
- **Reliability engineering** — observability, backup, network, security, and operational automation.

## Impact

- Built a Kubernetes Scheduler Extender and GitLab Runner workspace reuse system that made builds up to **7x faster** and reduced CI storage from approximately **2 TB to 400 GB**.
- Built private LLM infrastructure and authenticated API/MCP workflows handling **3,500+ daily calls** for **20+ engineers**.
- Standardized reusable delivery platforms and engineering practices supporting **50+ engineers**.
